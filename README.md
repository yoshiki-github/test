# Mobile Shooting Game

スマートフォンのブラウザで動作するシンプルなシューティングゲームです。

## ゲーム概要

- **ゲームタイプ**: 縦スクロール型シューティング
- **プレイ方法**: プレイヤーキャラを左右に動かして、上から落ちてくる敵を撃ち落とす
- **プラットフォーム**: モバイルブラウザ（スマートフォン・タブレット）、デスクトップブラウザ
- **実装**: Vanilla JavaScript + HTML5 Canvas

## 操作方法

### モバイル
- **移動**: 画面上の好きな場所にタッチして、プレイヤーが追従します
- **射撃**: 自動で連続射撃します

### デスコップ
- **移動**: マウスを移動してプレイヤーをコントロール
- **射撃**: 自動で連続射撃します

## ゲーム機能

✅ **ゲームメカニクス**
- プレイヤーキャラ（画面下）を左右に移動
- 敵は画面上から自動で落下
- プレイヤーが自動で弾を発射
- 敵に弾が当たると破壊される

✅ **難易度調整**
- 時間経過とスコア増加に伴い、敵の出現速度が上昇
- 難易度は段階的に上がっていく

✅ **ゲーム画面**
- スコア表示（敵1体あたり10ポイント）
- HP表示（初期値：3）
- メニュー画面
- ゲームオーバー画面

✅ **レスポンシブ対応**
- 様々な画面サイズに対応
- 高DPI対応（Retina ディスプレイ等）
- ポートレート・ランドスケープ両対応

## ローカル実行方法

### 1. 簡易 HTTP サーバーで実行

```bash
# Python 3
cd /path/to/project
python3 -m http.server 8000

# または Node.js (http-server)
npx http-server

# ブラウザで開く
# http://localhost:8000
```

### 2. VS Code Live Server拡張機能
VS Code で "Live Server" 拡張をインストールして `index.html` 上で右クリック → "Open with Live Server"

### 3. 直接ブラウザで開く
ファイルを直接ブラウザにドラッグ&ドロップ

## ゲーム画面

### メニュー画面
ゲーム開始時に「ゲーム開始」ボタンをタップ

### プレイ画面
- 上部左：スコア表示
- 上部右：HP表示
- 敵を倒してスコアを稼ぐ
- HP が 0 になるとゲームオーバー

### ゲームオーバー画面
最終スコアと「もう一度プレイ」ボタンが表示される

## ゲームプレイ TIP

1. **端に寄りすぎない**: 敵の軌道を読みやすくするため、画面中央付近に留まるのがおすすめ
2. **連続射撃**: 自動で射撃するため、敵に近い位置で待つと効果的
3. **難易度上昇**: スコアが増えると敵の出現速度が上昇するので、ゲーム進行に応じてペース配分を考える

## 実装ハイライト

🎮 **ゲームアーキテクチャ**
- Entity-based 設計で、Player、Enemy、Bullet を統一的に管理
- AABB (Axis-Aligned Bounding Box) 衝突検判
- デルタタイムベースの更新により、フレームレート非依存

📱 **モバイル最適化**
- タッチイベントとマウスイベント両対応
- ビューポート設定により、スマートフォン表示最適化
- 高DPI 対応で、Retina ディスプレイでも鮮明表示

⚡ **パフォーマンス**
- requestAnimationFrame による 60 FPS 実行
- オブジェクトプーリングで メモリ効率化
- Canvas 2D API の軽量描画
